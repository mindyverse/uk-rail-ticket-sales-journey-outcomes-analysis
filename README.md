# UK Rail  Ticket sales and Journey Outcomes Analysis

## Project Overview

The aim of this project is to gain an understanding of ticket purchasing patterns, gross ticket sales and journey outcomes by analysing a mock UK National Rail ticket dataset. There are 31,653 transactions in this dataset. Ticket purchasing details are available from December 2023 to April 2024 while journey details are available from January 2024 to April 2024. To carry out this analysis, I used Power BI, Power Query and DAX.



!\[Power BI Dashboard](dashboard.png)



## Questions that I wanted to answer

In this project, I mainly tried to find the answers to the following questions:

1. How many tickets were sold, and what was their total gross ticket sales  value?
2. What the routes had the highest number of transactions?
3. Which ticket types generated the highest gross ticket sales?
4. How were the journey records distributed among On Time, Delayed and Cancelled?
5. What were the main reasons for delays and cancellations?
6. How many refund requests were made for disrupted journey ?

## Data Preparation

First, i inspected the dataset before creating the dashboard.
I checked for missing values, duplicate transaction IDs, incorrect data types and inconsistent category names.
One of the main data cleaning issue i found was that some values with same meaning had different names in the 'Reason for delay' column.

For a instance:
-Weather conditions and Weather
-Signal failure and Signal Failure
-Staff shortage and Staffing

I standardised these values so that the same reason would not appear as two separate categories in the charts.
I did not delete the blank values in 'Reason for Delay' and 'Actual Arrival Time' columns. Because they are not always errors. For a example, it is normal for an On Time journey not to have a delay reason.
I also created a new column called 'Route' by combining 'Departure station' and 'Arrival destination' columns.

## Key measures

I created several main measures for the dashboard.

* Tickets Sold: 31,653
* Gross Ticket Sales: £741,921
* Average Ticket Price: £23.44
* On-Time Ticket Records: 86.82%
* Disrupted Ticket Records: 13.18%
* Refund Requests: 1,118

## Key findings

I identified the following findings from the analysis:

1. The highest gross ticket sales value, £309,274 was generated by Advance tickets.
2. There were 18,521 ticket transactions through online channel and 13,132 through station purchases.
3. Manchester Piccadilly - Liverpool Lime Street had the highest number of ticket transactions, with 4,628 transactions.
4. There were 27,481 ticket records marked as On time.
5. Weather was the most frequently recorded disruption reason among the cleaned delay-reason categories.
6. There were 1,118 refund requests among 4,172 disrupted ticket records.
